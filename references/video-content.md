# 视频内容和画面规则

## 内容方向

视频不默认做成产品介绍。根据用户主题选择以下模式：

- `auto`：具体梦境或梦境现象优先做故事；用户明确要求功能演示时才介绍平台。
- `product-demo`：围绕记录、整理、回看和解读梦境的真实使用场景表达。
- `dream-story`：围绕一个梦境片段、醒来后的感受或常见梦境现象展开，最后自然带出记录梦境的需求。
- `virtual-character`：以平台已有或用户提供的虚拟人物作为主要叙事者，演绎梦境，不需要仿真人。

默认优先使用原创虚拟人物、动画或插画角色，不使用真人演员、仿真人肖像或现实人物形象。用户提供固定虚拟人物设定时，保持其外观、服装、配色和性格一致。

## 界面真实性

这是最高优先级规则：

当前可用的真实页面截图见 [ui-reference.md](ui-reference.md)。

- 视频出现软件界面、网页、手机 App、按钮、表单或页面录屏时，只能使用经过确认的 `https://starpush.show/` 真实截图或录屏参考。
- 不得让模型自行设计、重绘、猜测或虚构 StarPush 的页面结构、文案、按钮、功能入口和数据。
- 当前小云雀 API 生成流程只发送文字提示词，没有实现本地参考图上传。因此当前默认禁止出现软件界面。
- 如用户明确要求界面演示，但没有提供真实截图或录屏，先停止生成并提示需要补充参考素材；不要用“看起来像官网”的假界面替代。

没有界面参考时，可使用虚拟人物、梦境场景、抽象意象、字幕和旁白表达产品价值，但不能把这些画面包装成真实产品界面。

## 产品边界

- 只使用产品资料中已经确认的能力。
- 不虚构价格、活动、用户数量、效果数据或功能入口。
- 梦境解读只能表述为中性自我观察和娱乐参考。
- 不使用医疗诊断、心理治疗、科学预测或确定性预言表述。
